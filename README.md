# Claude Desktop 中文语言包

这个仓库打包了 Claude Desktop macOS / Windows 中文语言包插件，插件目录：

```text
claude-desktop-zh-crossplatform/
```

## 快速使用

macOS：

```bash
cd claude-desktop-zh-crossplatform
chmod +x ./install-mac.command
./install-mac.command
```

Windows：

```text
右键 claude-desktop-zh-crossplatform\install-windows.bat，以管理员身份运行
```

默认安装模式只添加中文语言资源和前端语言选项，不修改 `app.asar`。如果需要修复 3P gateway 模型名校验，可在安装菜单里选择 Advanced 模式。

详细说明见：

```text
claude-desktop-zh-crossplatform/README.md
```
